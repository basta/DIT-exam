# Question
Define an **atom** of a boolean algebra, and the boolean algebra $\mathcal{C}^{\mathrm{bool}}$ generated by a collection. (HW2, stated definition)

# Solution
**Correct Answer:** An **atom** of a boolean algebra $\mathcal{C}$ is a minimal element (with respect to inclusion) of $\{A \in \mathcal{C} : A \ne \varnothing\}$ — a nonempty set in $\mathcal{C}$ with no nonempty proper subset in $\mathcal{C}$. $\mathcal{C}^{\mathrm{bool}}$ is the smallest boolean algebra of subsets containing $\mathcal{C}$.

## Explanation
Atoms are the "indivisible pieces" of a boolean algebra: every element is a (disjoint) union of atoms when the algebra is finite/atomic.

If $\mathcal{C} \subseteq \mathcal{P}(X)$ has cardinality $|\mathcal{C}| = n$, HW2 Ex 0.2 asks for bounds:

- the $n$ generating sets cut $X$ into at most $2^{n}$ **atoms** (the nonempty cells of the form $\bigcap_i A_i^{\pm}$, each $A_i$ in or complemented);
- hence $\mathcal{C}^{\mathrm{bool}}$ has at most $2^{2^{n}}$ elements (all unions of atoms), and is exactly the set of unions of atoms.

HW2 Ex 0.3 ("how many boolean algebras on a set of size $n$?") is the **Dedekind/Bell-number** flavored count: a boolean algebra of subsets of a finite set is determined by a **partition** into atoms, so the number of boolean *sub*algebras of $\mathcal{P}(X)$ equals the number of partitions of $X$, the Bell number $B_n$.

This is the finite, combinatorial shadow of cell decomposition: definable sets are finite unions of atoms (cells).
